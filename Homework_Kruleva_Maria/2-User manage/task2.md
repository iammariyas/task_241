# Запрещаем

1. **Запретите пользователю user1 из предыдщуего задания выполнять вход в систему**
	Чтобы запретить входить пользователю user1 можно применить следующие способы:
	`sudo usermod -s /bin/false user1` - меняет shell на недействительный, блокируя интерактивный вход (SSH, консоль).
	
	Проверим, что мы действительно заблокировали его и восстановим ему вход в систему:

2. **Как вы это сделали?**
Ввела команду `sudo usermod -s /bin/false user1`, далее, чтобы проверить, что действительно пользователь не может выполнять вход, ввожу команду `cat /etc/passwd`. Там есть вывод, который говорит, что пользователь не может входить:
```
/home/user1:/bin/false/
```
	
3. **Какие ещё способы это сделать вы знаете?**\
	2 способ:
	`sudo passwd -l user1` - блокирует пароль, запрещая логин по паролю.
	3 способ:
	Для полного запрета: `sudo usermod -L user1` - блокирует имя пользователя.
4. **Можно ли создать пользователей с одинаковыми username?**
	нет, нельзя создать двух пользователей с одинаковыми username, так как имя уникально в файле `/etc/passwd`. Система выдаст ошибку при попытке `useradd username`, если такой уже существует.
