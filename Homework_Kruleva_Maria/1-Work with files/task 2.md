### Перенаправляем

#### 1. 1. Как работают команды >,>>?

Есть три основных потока:
- **Стандартный ввод (stdin)** - поток, откуда программа получает данные. Например, ввод данных с клавиатуры
- **Стандартный вывод (stdout)** - поток, куда программа отправляет результаты. Вывод в терминале, например
- **Стандартный поток ошибок (stderr)** - поток для сообщений об ошибках. 

Команды > и >> используются для перенаправления вывода.

> \> `file` - направить стандартный поток вывода в файл. Если файл не существует, он будет создан, если существует - перезаписан сверху.
> 
> \>> `file` - направить стандартный поток вывода в файл. Если файл не существует, он будет создан, если существует - данные будут дописаны к нему в конец.
#### 2. Что такое перенаправление ввода? stderr, stdout;

Перенаправление ввода - возможность использовать данные из файла, а не с клавиатуры, в качестве входных данных. 

Чтобы использовать перенаправление ввода, нужно ввести команду с ее параметрами и аргументами, за которыми следует символ < и путь к файлу, который будет использовать для ввода.

````
python3 myscript.py < input.txt
````

Как уже говорилось в задании 1: стандартная ошибка (stderr) - поток для сообщений об ошибках, стандартный вывод (stdout) - поток, куда программа отправляет результаты. 

Потоки пронумерованы:

- stdin - 0,
- stdout - 1,
- stderr - 2.

Чтобы перенаправить сообщения об ошибках, нужно использовать дескриптор файла, который для стандартной ошибки имеет номер 2. `2>` - так ошибка будет перенаправлена в файл. Ниже будут примеры. 2>> перенаправит ошибку в конец файла, если его не существует - создаст. Покажу примеры:

Допустим, есть команда `ls`. Она создает список файлов и выводит его в стандартный вывод (stdout), то есть в окно терминала, но если захотеть сохранить весь вывод в файл, это можно сделать, перенаправив поток. Для этого можно использовать >.

`ls > output.txt` - в таком случае, теперь список файлов сохранится в этот файл, а не выведется на экран.

Мы можем использовать >>, чтобы перенаправить стандартный вывод команды в файл, добавляя данные в конец существующего файла.

`echo "lalala" >> output.txt`. Эта команда добавит "lalala" в конец файла `output.txt`, не удаляя предыдущее содержимое, но если этого файла не существует, ошибки не будет, файлик просто будет создан.

#### 5. Перенаправить stdout в stderr и обратно на примере команды kinit, ping, tracert

Команда ping отсылает пакеты на сайт, который мы указали (google.com), и анализирует. Справа мы можем увидеть значение time. Значение time показывает, за сколько времени данные доходят до google.com и возвращаются обратно, в миллисекундах.

Сначала на скрине я показываю как работает эта команда, вывела два пакета.  Затем перенаправляю в `stderr` с помощью команды `ping -c 2 google.com >&2`. Хотя визуально вывод идентичен, технически я перенаправила данные из стандартного потока вывода в стандартный поток ошибок.

![[Pasted image 20251111231451.png]]
Теперь обратно перенаправим с `stderr` на `stdout`. Сначала я вызову ошибку, просто указываю набор букв вместо имени сервера, а затем перенаправляю в стандартный поток вывода. 
![[Pasted image 20251111231618.png]]

В Windows эта команда называется Tracert, а в Linux и MacOS – Traceroute.

**Traceroute** или **Tracert** - это утилита, служащая для диагностики сети. Она отслеживает пути, по которым пакеты данных проходят от источника к хосту назначения, что позволяет администраторам оперативно решить проблемы с подключением. Traceroute сопоставляет каждый переход, предоставляет подробную информацию и время приема-передачи (RTT), а также, по возможности, сообщает имя устройства и IP-адрес. В то время как команда Ping может сообщить, есть ли проблема, Traceroute поможет точно определить, где именно она образовалась.

`traceroute -m 5 google.com 1>&2`. В этой команде я выполняю трассировку маршрута до google.com с ограничением в 5 прыжков, при этом перенаправляю весь стандартный вывод в поток ошибок. Опять же, визуально результаты выглядят идентично, но технически здесь он проходит через `stderr`, а вот здесь: `traceroute -m 5 google.com 2>&1` - проходит через `stdout`.

#### 6. Чем отличаются stdout и stderr
Оба потока предназначены для вывода текста: `stdout` - это стандартный поток вывода, а `stderr` - это стандартный поток вывода ошибок. В `stdout` данные могут накапливаться перед выводом, в `stderr` же сообщения выводятся немедленно. Также в `stderr` высокий приоритет для донесения информации до пользователя, даже если основной вывод перенаправлен.

#### 7. Что такое stdin?
`stdin` - стандартный поток ввода, из которого программа читает данные. Обычно эти данные поступают от пользователя через клавиатуру, но могут приходить из файлов или других программ. Программа может забирать данные один за другим из этого потока, пока не достигнет конца ввода.
#### 8. Как отправить весь вывод команды в пустоту?
Чтобы весь вывод отправить в пустоту, можно его перенаправить в `/dev/null`

`команда > /dev/null`

`/dev/null` - это специальный файл, который присутствует в каждой системе Linux. Однако, в отличие от большинства других виртуальных файлов, вместо чтения он используется для записи. Все, что вы запишете в `/dev/null`, будет отброшено, забыто в пустоте. В системе UNIX он известен как нулевое устройство. Он удаляет все записанное в него и возвращает при чтении EOF.

В некоторых ситуациях вывод может оказаться бесполезным. Используя перенаправление, мы можем сбросить весь вывод в пустоту.
