# **Конфижим для удобства**

1. **Где хранятся пользвательские и системные настройки подключения?**
	`/etc/openssh/sshd_config` - хранятся ssh-сервер настройки, а в `~/.ssh/config` - собственные подключения.
	
2. **Что за файл options?**
	Файл options относится к конфигурация ssh клиента или сервера **`~/.ssh/config`** (для конкретного пользователя) или `/etc/ssh/ssh_config` (глобально для системы), где хранятся **опции (параметры) для управления соединениями**, включая настройки хоста, пользователя, порта, ключей, шифров и прокси, чтобы избежать повторного ввода длинных команд, а также к **серверному файлу `/etc/ssh/sshd_config`** для настроек самого SSH-сервера (сервиса).
