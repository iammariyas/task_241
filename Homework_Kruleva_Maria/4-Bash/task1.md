# Скриптуем по полной

1. **Что такое шебанг?**
	Это строка комментария, начинающаяся с символов #!. Она играет важную роль в запуске скриптов на Bash. Шебанг указывает ОС, какой интерпретатор нужно использовать для выполнения скрипта. 
	```
	#!<interpreter> [arguments]
	```
	- #! - сам шебанг, с которого начинается директива.
	- \<interpreter> - путь к интерпретатору, который должен быть использован для выполнения скрипта. Данный путь всегда должен вести к бинарному файлу, например `/bin/bash`.
	- `[arguments]` - аргументы к исполняемому файлу. опция не является обязательной.
	```
	#!/bin/bash
	```
	фактически это путь к интерпретатору нашего скрипта.
2. **Обязательно ли исполняемый файл должен иметь соответствующее расширение?**
	Нет. в линухе признаком исполняемого файла являются права доступа (бит выполнения x), а не расширение. 
	
	файл становится исполняемым, если ему установлен бит выполнения
	`chmod +x myfile`
	
3. **Напишите скрипт который выполнит автоматически действия из блока работы с файлами. ( не забудьте включить set -euo pipefail для того что бы ваш скрипт было удобнее отлаживать. Опишите что включают эти флаги)**
	Описание флагов:
	-e скрипт останавливается при любой ошибке команды (exit code != 0)
	-u - обрабатывает неопределённые переменные как ошибку
	-o pipefail - ошибка пайплайна останавливает скрипт
	Скрипт выглядит следующим образом:
	![alt text](https://github.com/iammariyas/task_241/blob/labs/Homework_Kruleva_Maria/image/Pasted%20image%2020251230010955.png)
	Создаем тестовую папку и файлы 
	```
	mkdir -p /tmp/test_dir 
	touch /tmp/test_dir/{lala.txt,ff.txt,log.log} 
	echo "Созданные файлы:" 
	ls -la /tmp/test_dir/
	```
	Теперь изменим владельца:
	`chown $USER:$USER /tmp/test_dir/*`
	Перемещаем и переименовываем файл:
	```
	mv /tmp/test_dir/lala.txt /tmp/doc.txt 
	chmod 644 /tmp/doc.txt
	```
	Вывод файлов в тестовой папке:
	```
	echo "Файлы в /tmp/test_dir:" 
	ls -la /tmp/test_dir/ 2>/dev/null || echo "Папка пуста или удалена"
	```
