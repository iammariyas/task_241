6. **Что такое ip адрес?**
	это уникальный номер, нужный для распознавания устройства в интернете или в локальной сети. он помогает понять, куда отправлять и откуда получать данные.
	айпи адрес предоставляет возможность различать разные компьютеры, маршрутизаторы и веб-сайты. айпи адреса составляют важную часть работы интернета
7. **Для чего нужны маршруты?**
	маршруты - это пути, по которым пакеты данных перемещаются от отправителя к получателю.
	они нужны для того, чтобы данные доходили от одного устройства к другому, даже если они находятся в разных сетях.
8. **Что за протокол arp?**
	это сетевой протокол, который помогает преобразовать известный ip-адрес в соответствующий ему MAC-адрес в локальной сети. расшифровывается arp как adress resolution protocol, то есть протокол разрешения адресов.
	сам протокол имеет буферную память (arm-таблицу), в которой хранятся пара адресов ip и mac адрес, с целью того, чтобы уменьшить количество посылаемых запросов, а следовательно, экономии трафика и ресурсов.
9. **Что такое dhcp?**
	это сетевой протокол, позволяющий компьютерам автоматически получать IP-адрес и другие параметры, необходимые для работы в сети. расшифровывается как dynamic host configuration protocol - протокол динамической настройки узла.
	
	его цель/предназначение - устранить два основных ограничения, накладывающихся на другие аналогичные протоколы. а именно: отсутствие поддержки динамического назначения айпи адресов и возможность передавать от сервера на станцию-клиент небольшое число параметров конфигурации.
10. **Что такое dns?**
	domaine name system - это система, которая переводит понятные человеку доменные имена в IP-адреса, которые используют компьютеры для связи друг с другом.
11. **Как называется один из протоколов синхронизации времени?**
	NTP (network time protocol - протокол сетевого времени) является стандартным протоколом для синхронизации времени в интернете и локальных сетях. он обеспнчивает высокую точность и устойчив к сетевым задержкам, работает через udp.
	есть еще также SNTP - простой протокод сетевого времени и ptp - протокол точного времени.
12. **Что такое широковещательный запрос, зачем он нужен?**
	broadcast request или широковещательный запрос - это сетевое сообщение, которое отправляется одним устройствам всем другим устройствам в пределах одного локального сегмента сети, а не конкретному получателю. такой способ эффективно помогает распространять  информацию, например, при обнаружении dhcp сервера, выполнении arp запросов или отправке системных уведомлений всем участникам сети одновременно
13. **Какой адрес является широковещательным?**
	broadcast addres или широковещательный адрес - это специальный, зарезервированный адрес в компьютерной сети, который используется для одновременной отправки пакетов данных всем устройствам в этой сети, а не конкретному получателю.
	основные примеры - это mac адрес - он всегда широковещательный, ip адрес (IPv4) - `255.255.255.255` - общий широковещательный адрес и есть сетевой широковещательный ip адрес - последний адрес в подсети. например, для сети `192.168.1.0/24` широковещательный адрес будет `192.168.1.255`

15. **Что такое маска подсети? зачем она нужна?**
	маска подсети - это параметр, определяющий, какая часть ip-адреса относится к сети, а какая к хосту.
	маска подсети позволяет компьютеру идентифицировать устройства внутри одной сети, и понимать, кто не в ней.
