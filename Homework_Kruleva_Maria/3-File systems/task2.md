# Струтура каталогов

1) **Какая структура каталогов в linux? выведите список файлов в корне системы**
	 ФС в Линуксе организована в виде вложенных друг в друга каталогов, как дерево. В ее основе лежит корневой каталог, а из него, подобно ветвям, могут создаваться другие каталоги (папки), а внутри них - файлы и дополнительные вложенные каталоги. Таким образом, вся структура строится от одного начального пункта - корня, в котором хранится или из которого "произрастает" все остальное содержимое системы.
	 
	Посмотрим на картинке:
	
	![[../image/Pasted image 20251229193509.png]]
	
	Чтобы вывести список файлов и каталогов в корневой ФС используется команда:
	```
	ls /
	```
	если хочется увидеть более подробную информацию:
	```
	ls -l /
	```
	
	![[../image/Pasted image 20251229195049.png]]
	
	а чтобы увидеть и скрытые файлы:
	```
	ls -la /
	```

2) **Где хранятся папки пользователей в системе?**
	`/home` — домашние каталоги пользователей. Помогает организовывать безопасную работу пользователей в многопользовательской системе. Вне своего домашнего каталога пользователь обладает минимальными правами (обычно - чтение и выполнение файлов), не может нанести ущерб системе, например, удалив или изменив файл.
	
	Кроме файлов, созданных пользователем, в его домашнем каталоге обычно содержатся персональные конфигурационные файлы некоторых программ.
	
3) **Где домашняя папка суперпользователя?**
	Домашняя папка суперпользователя (root) находится по пути `/root/`
4) **Где хранятся основые конфигурационные файлы в системе?**
	В каталоге `/etc` хранятся системные конфигурационные файлы, в т.ч. настройки сети, пользователей, служб и загрузки. Здесь также находятся сценарии запуска и завершения работы, используемые для старта и остановки отдельных программ.
	**Примеры:**
	- `/etc/fstab` - таблица монтирования файловых систем
	- `/etc/passwd`, `/etc/shadow` - пользователи и пароли
	- `/etc/group`, `/etc/gshadow` - группы
	- `/etc/hosts` - таблица hosts
	- `/etc/resolv.conf`- DNS-серверы
	- `/etc/ssh/sshd_config` - SSH сервер
	- `/etc/sudoers`, `/etc/sudoers.d/` - права sudo
	- `/etc/systemd/`- конфиги systemd
	
5) **ЧТо за папки /bin,/sbin,usr/bin,/usr/sbin**
	**`/bin` и `/sbin`**
	- `/bin` - командные оболочки (shell), основные утилиты
	- `/sbin` - набор программ для административной работы с системой (системные утилиты)
	**`/usr/bin` и `/usr/sbin`**
	- `/usr/bin` - дополнительные программы для всех учетных записей
	- `/usr/sbin` - команды, используемые при администрировании системы и не предназначенные для размещения в файловой системе root
