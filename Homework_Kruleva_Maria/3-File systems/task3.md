1. **Выведите содержимое fstab. Что хранится в fstab?**
	***File System Table (fstab)*** - это конфигурационный файл, который определяет, какие файловые системы должны монтироваться автоматически при загрузке системы. Это важный элемент для любого администратора сервера, будь то физический сервер или виртуальный сервер (VPS). 
	
	обычно находится в `/etc/fstab` и состоит из строк, каждая из которых описывает отдельную файловую систему. Стандартная строка в `fstab` имеет следующий формат: `<файловая система> <точка монтирования> <тип> <опции>`.
	
	Содержимое `fstab` можно посмотреть с помощью команды `cat /etc/fstab`

8. **Сделайте так чтобы диск автоматически подключался при загрузке систем ( добавьте информацию о нём с fstab)**
	Сначала нужно узнать UUID раздела с помощью команды `blkid /dev/sdb`, текст будет выглядеть примерно так:
	`/dev/sdb1: UUID="номер UUID" TYPE="ext4"`, затем в конец файла `nano /etc/fstab` дописываю: 
	`UUID=номер_UUID  /mnt/mydisk  ext4  defaults  0  2`. После этого перезагружаю систему.  И сразу после этого ввожу команду `df -h /mnt/mydisk` и диск уже должен быть смонтирован. 
	
9. **Проверьте корретность записанных в fstab данных перед перезагрузкой**
	```
	mount -a
	```
	Команда `mount -a` монтирует все файловые системы из `/etc/fstab`. Если есть ошибки - они будут показаны.
